# Candidate configuration

The three historical JSON files in this directory define the unchanged Luwanga Pipeline 001 configuration and hash. Do not rewrite them to activate another language.

Opt-in language profiles use the [version 1 contract](../../docs/research/multilingual-pipeline-configuration-001.md) and the existing runner's `--language-profile` option. Explicitly synthetic profile/snapshot examples live in `tests/fixtures/multilingual`; no real language configuration or approval is seeded by this milestone. Unsupported features fail explicitly, and real-data profile execution remains gated on a future authorized private exporter.
